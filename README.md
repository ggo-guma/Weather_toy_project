## 📌 Intro

```
매일 아침 날씨 예보를 보지 못하거나, 우산을 깜빡하는 경우가 있지 않나요 ? 
꼬구마의 기상 알림 시스템과 함께라면 잊을 일 없을거에요 ! 
비 오는 날, 마음까지 젖지 않게 – 우산과 꼬구마처럼 따뜻한 하루 되세요 ~
```

- 사용 대상 : 기상예보 및 날씨 앱을 보지 않고 비 오는날 우산을 깜빡하고 나오지 않은 사람들
- 문제 의식 : 최근 기후변화로 인한 이상기후 현상이 심화되면서, 날씨 예측의 정확도가 낮아지고 있다. 이러한 예측 불확실성은 개인의 일상 속 준비 부족(예: 우산 미지참)은 물론, 일정 변경, 참가자 불편, 장비 손상 등 다양한 문제를 초래
    
    이에 따라 사람들의 날씨에 대한 사전 대응의 정확도 및 안정성을 높이기 위해, 클라우드 기반의 스마트 기상 예측 및 선제 알림 시스템을 구축
    



### 📍 프로젝트 목표

- **비 오는 날, 우산 없이 나서는 사람들을 위한 사전 알림 서비스 필요**
    
    → 기상앱을 자주 확인하지 않는 사용자를 위한 실용적 해결책 제시
    
- **이상기후로 인해 날씨 예측의 불확실성이 증가하고 있음**
    
    → 기후 변화에 따른 예측 어려움 및 일상/행사 운영 차질 문제 인식
    
- **안정성을 높이기 위한 클라우드 기반 스마트 기상 알림 시스템 구축**
    
    → 기상 정보 api 와 클라우드를 활용한 선제 대응 체계 마련
    


### 🛠️ 사용기술

- AWS
    - Event Bridge
    - Lambda
    - SNS ( Simple Notification Service )
    - Cloud watch
    - EC2
- Grafana
